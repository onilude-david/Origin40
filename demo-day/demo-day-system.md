# Origin40 — Demo Day System

Operational data: tab `16 · Demo Day Plan`, `17 · Demo Day Schedule`, `18 · Judge Scoring`,
`18b · Leaderboard`. Format: **3-minute pitch + 2-minute Q&A** per founder.

---

## 1. Planning Tracker (tab 16)

Workstreams: **Venue/AV · Judges · Founders (rehearsals) · Investors · Media · Awards · Logistics.**
Each task has Owner, Due date, Status, Priority; "Days to Due" auto-flags overdue.

**Countdown checklist:**
- **T−14:** venue + date locked; investor pack drafted; judges shortlisted.
- **T−7:** judges confirmed; founder rehearsal #1; invites + RSVPs live; media outreach sent.
- **T−3:** run-of-show final; AV test; rehearsal #2; certificates + awards printed.
- **T−1:** tech check at venue; backup demo videos collected; investor packs printed.
- **Day:** doors, run show, capture content, awards, investor mingle.

---

## 2. Run-of-Show (tab 17 — adjust times)

Welcome → partner remarks → Pitch Block A → break → Pitch Block B → judges deliberate (founder expo)
→ awards + certificates → closing + investor mingle. (Default schedule seeded in tab 17.)
Each founder: **3 min pitch + 2 min Q&A.** Strict timekeeping — a visible timer + a timekeeper.

---

## 3. Judge Scoring Rubric (→ tab `18 · Judge Scoring`)

One row per judge per founder; weighted **Total /80** auto-computes; `18b` averages per founder.

| Criterion | /10 | Look for |
|---|---|---|
| Problem clarity | | Specific, real, painful problem |
| Product progress | | A working product, not just slides |
| Market opportunity | | Size + "why now" |
| Validation evidence | | Real users, real feedback, traction |
| Business model | | Credible path to revenue |
| Founder strength | | Coachability, grit, insight |
| Pitch quality | | Clear, confident, on-time |
| Impact potential | | Value to users / Africa |

Awards (suggested): **Best Product · Best Pitch · Most Validated/Traction · People's Choice ·
Judges' Choice (overall winner).** Winner = highest average in `18b · Leaderboard`.

---

## 4. Investor / Funder Pack (structure)

1. Cover: Origin40 + Demo Day date + the legacy line.
2. The cohort: 40 founders, sectors at a glance.
3. **Founder one-pagers** (1 page each): problem · product · traction · ask · contact.
4. How to engage: warm intro process + who to contact.
5. About Origin40 + partners (Beere Softwares, Equip Africa, Dooke, Anfani).

Feed each founder one-pager from Week 4 deliverables + tab `19 · Follow-Up Tracker` funder readiness.

---

## 5. Founder Showcase Structure (per founder pitch)

Hook (15s) → Problem + customer (45s) → Solution + **live demo** (60s) → Traction (30s) →
Business model + **the ask** (30s). Backup demo video mandatory. (See `curriculum/week4`.)

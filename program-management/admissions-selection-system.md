# Origin40 Admissions & Selection System

## Purpose

Origin40 should admit early founders who can show up, build, learn fast, and safely participate in a 4-week online incubator. The admissions system separates three things:

- Eligibility checks: hard requirements that decide if an application can move forward.
- Founder quality review: scored judgment on problem, seriousness, product, market, build readiness, and availability.
- Final selection: human decision based on fit, cohort balance, and seat availability.

## Application Gate Checks

Every imported or manually added application is assessed against these checks in the dashboard.

| Check | Type | What It Means | Failed Result |
| --- | --- | --- | --- |
| Reachable applicant | Required | Name, country, and email or phone are captured. | Reject / Fix Required |
| Clear startup or idea | Required | Startup name, idea, or one-line pitch exists. | Reject / Fix Required |
| Laptop/internet readiness | Required | Applicant has the tools to join and build online. | Reject / Fix Required |
| Monday/Friday live availability | Required | Applicant can attend core live sessions. | Reject / Fix Required |
| Review/data consent | Required | Applicant agrees that Origin40 can review the submitted data. | Reject / Fix Required |
| Accuracy confirmation | Required | Applicant confirms the information is true. | Reject / Fix Required |
| Problem clarity signal | Important | The problem being solved is understandable. | Hold / Clarify if weak with other gaps |
| Build ownership | Important | Someone is responsible for building or driving the build. | Hold / Clarify if weak with other gaps |
| 10-15 hour weekly commitment | Important | Applicant can give enough time to the program. | Hold / Clarify if weak with other gaps |
| Discord communication readiness | Important | Applicant can use Discord as official communication. | Hold / Clarify if weak with other gaps |

## Recommended Moves

| Move | Meaning | Team Action |
| --- | --- | --- |
| Select | Strong score and required checks are clear. | Move to selected list after final review. |
| Shortlist | Checks are clear and the founder looks program-fit. | Schedule review or accept if seats are available. |
| Needs Review | Not enough signal yet for a confident decision. | Score manually and inspect raw answers. |
| Hold / Clarify | Important gaps exist but not automatic rejection. | Ask follow-up questions. |
| Reject | Score is below the minimum quality bar. | Reject politely after reviewer confirmation. |
| Reject / Fix Required | A required check failed. | Reject or request correction if the issue is fixable. |

## Reviewer Workflow

1. Open Applications in the dashboard.
2. Start with the Admissions Gate summary.
3. Review everyone marked Shortlist or Select first.
4. Open each applicant drawer and inspect the checklist.
5. If the applicant is promising but missing a non-required signal, use Hold / Clarify.
6. Score the applicant with the 100-point rubric.
7. Apply the final status: Under Review, Shortlisted, Selected, Waitlisted, or Rejected.

## Manual Override Rules

The system should guide decisions, not replace judgment. A reviewer may override the recommendation when:

- The applicant is exceptionally strong but imported data missed a field.
- A required answer is unclear and can be verified quickly.
- The cohort needs balance across sectors, geography, gender, or technical skill.
- A legal/risk note needs human review before acceptance.

## Minimum Standard

For Origin40, the minimum bar is not "perfect startup." The minimum bar is:

- A real problem or serious idea.
- A founder who can commit time.
- Ability to join online sessions.
- Willingness to communicate on Discord.
- Enough build ownership to make progress in 4 weeks.
- Honest and complete application data.

# Design Context

## Target Audience

Origin40 operators, program managers, admissions reviewers, facilitators, and partner-facing team
members running a 4-week build-focused incubator for 40 early-stage African founders.

## Use Cases

- Monitor application intake, scoring, shortlist status, and founder selection.
- Import real applicant data from Fluent Forms CSV exports.
- Track founders, mentors, facilitators, partners, Demo Day readiness, and impact documents.
- Open key external resources quickly: WordPress site, registration form, Discord, LMS, Drive, Demo Day.
- Review and download curriculum, operations, mentor, sponsor, and form documents.

## Brand Personality / Tone

Operational, focused, founder-serious, warm, and credible. The UI should feel like a real cPanel for
running an incubator: quiet, dense, structured, and fast to scan. It should avoid marketing-page
hero layouts, decorative gradients, and generic dashboard clutter. The design should feel modern and
African founder ecosystem-aware without becoming loud or ornamental.

## Design Direction

Industrial editorial command center: a light, disciplined workspace with a deep ink sidebar, warm
paper surfaces, green execution accents, and amber attention states. The memorable quality should be
the sense of an organized program room: everything has a place, key numbers are visible, and operators
can move quickly.
